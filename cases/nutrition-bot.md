# Nutrition Bot

[← Все проекты](../README.md) · [Бот](https://github.com/adpetrovskiy-dot/nutrition-bot-) · [Telegram Web App](https://github.com/adpetrovskiy-dot/nutrition-bot-webapp)

Дневник питания внутри Telegram: настройка профиля, расчёт калорий и БЖУ, добавление продуктов и просмотр статистики.

## Что реализовано в коде

- Пошаговое заполнение профиля и расчёт ориентировочных норм.
- Текстовый ввод еды, поиск продуктов в Open Food Facts и сохранение в SQLite.
- Поиск продукта по фотографии штрих-кода с возможностью ручного ввода кода.
- Учёт порций, приёмов пищи и просмотр статистики.
- Отдельный интерфейс Telegram Web App с показателями калорий, белков, жиров и углеводов.

**Стек:** Python, aiogram, aiosqlite, aiohttp, HTML, CSS, JavaScript, Telegram Web App API.

Голосовое распознавание в текущем публичном коде отключено. Мини-приложение требует подключения к собственному API статистики по HTTPS; опубликованный интерфейс сам по себе не является работающим сервисом. Платёжный магазин не заявляется как реализованная возможность этих репозиториев.
